# Feather Client

**Feather Client** is the Minecraft Java launcher: 40 built-in mods, voice chat, Fabric / Forge import, HUD, FPS boost.

## How to use
1. Download v0.2.0.338.
2. Extract `Feather-Client.zip`.
3. Login a Microsoft account.
4. Pick 1.8.9 / 1.20.1 / 1.21. Launch.
